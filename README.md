## Features
- Time accurate to the second with ±5ppm drift
- Board temperature monitoring within ±0.5°C
- Dual USB power output up to a combined 1.5A
- Independent USB current/voltage measureement
- On board USB-Serial converter for easy programming/syncing
- Analog display brightness
